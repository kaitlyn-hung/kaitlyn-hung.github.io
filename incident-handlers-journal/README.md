### Entry #1 - Investivating a suspicious file hash 
**Date**: September 26, 2025  

**Tools Used**: For this activity, I used **VirusTotal**. It scans files and URLs for malware such as viruses, trojans, and worms. It’s useful for quickly checking whether a file or website has been flagged as malicious by the cybersecurity community. I analyzed a suspicious file hash that had been reported as malicious.  

**The 5 W's**: 
+ **Who**: An unidentified malicious actor
+ **What**: An employee received an email containing a malicious file attachment with the SHA-256 hash: 54e6ea47eb04634d3e87fd7787e2136ccfbcc80ade34f246a12cf93bab527f6b
+ **Where**: Employee’s computer, financial services company
+ **When**: At 1:20 p.m., the SOC received an alert triggered by the intrusion detection system detecting the file
+ **Why**: The employee downloaded and executed the malicious email attachment, allowing potential compromise

**Additional Notes**: This exercise simulated the Detection and Analysis phase of an incident. Acting as a SOC analyst, I investigated the alert generated by security systems to determine whether it represented a genuine threat.

### Entry #2 - Analyzing a packet capture file
**Date**: September 30, 2025  

**Tools Used**: For this activity, I used **Wireshark** to analyze a packet capture file. As a network protocol analyzer, Wireshark enables me to inspect network traffic and identify signs of suspicious or malicious activity.  

**Additional Notes**: Never used, or heard of, Wireshark prior to this activity, so I was interested in learning how to utilize it for analyzing a packet capture file. At first, the interface felt a bit overwhelming, but I quickly realized how powerful it is for examining and understanding network traffic.

### Entry #3 - Capturing my first packet
**Date**: October 1, 2025  

**Tools Used**: For this activity, I used **tcpdump** to capture and examine network traffic. Tcpdump is a command-line network protocol analyzer. Like Wireshark, it’s valuable in cybersecurity because it lets me capture, filter, and analyze network data to investigate activity on a network.  

**Additional Notes**: I am now able to distinguish the differences between **Wireshark** and **tcpdump**. Tcpdump is a command-line tool for capturing and analyzing network traffic, while Wireshark provides a graphical interface for visualizing and exploring packets.
